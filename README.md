# 晶格候选室（Lattice Candidate Chamber）

从一组衍射反射向量审阅多个可能晶格的 Web 应用：导入峰坐标、强度、测量协方差
与仪器校准版本后，系统生成多个晶格候选，并为每个反射给出 hkl、预测位置、
残差与离群判定；晶胞约化与坐标变换过程完整记录。Python + FastAPI + NumPy +
SQLite，计算过程不访问外网。

## 安装与运行

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest -q
.venv/bin/uvicorn app:app --host 127.0.0.1 --port 5260
```

打开 http://127.0.0.1:5260 ，页面标题为“晶格候选室”。点击“载入示例数据”
再点击“生成候选”即可看到双晶域合成数据上的候选族。

## 功能

- **原始观测保存**：倒易坐标、强度、3×3 测量协方差（上三角 6 元素）、校准版本。
- **多候选生成**：从最短观测向量枚举三重轴，排除奇异/近共面基（固定容差
  `SINGULAR_TOL`、`MIN_NORM_DET`），按快速指标化计数稳定排序后逐个约化与评分。
- **四分评分量分列展示**（不合成单一总分）：已索引比例、加权残差（马氏距离）、
  复杂度（约化胞体积）、离群预算（已用/预算，超出标记）。
- **晶胞约化与变换链**：`reduce_basis` 的每一步都是整数单模矩阵并入库；
  hkl 点击可回溯到原始观测、残差与完整变换链。
- **候选族**：等价晶胞经整数单模基变换归为同族，变换矩阵与原候选均保留；
  近似相同但超出 `FAMILY_TOL=1e-6` 的候选不合并。
- **人工标记与局部过期**：可锁定/排除反射、调整校准点、从当前分析分叉；
  只有依赖被改反射的候选过期，校准修改则全部候选过期。
- **冻结**：一次冻结钉住校准、容差与人工标记；草案版本乐观并发，
  冻结旧草案返回 409。

## 文件

- `lattice_core.py`：容差、晶胞约化、指标化、评分、候选生成、族分组。
- `store.py`：SQLite 表结构、过期传播、分叉、冻结版本控制。
- `sample_data.py`：固定种子的双晶域/系统消光/峰重叠/标定偏差/离群合成数据。
- `app.py`：FastAPI 路由。
- `static/index.html`：倒易空间投影、候选族、反射对应、残差分布、变换链面板。
- `tests/`：等价基、双晶域、缺失反射、并列候选、奇异基、离群预算、
  协方差权重、局部过期、冻结冲突、分叉隔离。
